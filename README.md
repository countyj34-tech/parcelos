# Swift Africa

You are a Senior Product Designer and Enterprise SaaS UI/UX Expert.

Design a modern, premium, responsive Courier Management SaaS platform that will be used by courier companies across Africa.

The design should be clean, elegant, enterprise-level, and comparable to Stripe Dashboard, Linear, Notion, Shopify Admin, and Vercel.

The application is NOT for one courier company.

It is a multi-tenant SaaS platform where every courier company has its own workspace.

The platform must support:

• Courier Companies

• Branches

• Receptionists

• Dispatch Officers

• Drivers

• Customers

Use React + TypeScript + TailwindCSS + shadcn/ui.

The design should use rounded cards, beautiful tables, premium dashboards, subtle animations, professional spacing, excellent typography, icons from Lucide React, and excellent UX.

Avoid clutter.

Everything must feel premium.
